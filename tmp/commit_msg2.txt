fix(auth): perbaiki login gagal - URL API balik ke server produksi

Penyebab: commit "Minor Update" (68959f6) mengubah kApiBaseUrl dari
server produksi menjadi http://localhost:3000/api dan itu ter-rilis
di APK v20260923-1210.

Akibatnya di HP, panggilan ke /auth/google mengarah ke HP itu sendiri
(connection refused), sehingga _postToAuth() selalu gagal dan login
menampilkan "Login dibatalkan" walau akun Google berhasil dipilih.
Semua fitur lain (scan, laporan, update, voice) juga mati karena
tidak bisa menjangkau server.

Perbaikan:
- config.dart: default kApiBaseUrl kembali ke server produksi Railway.
  Override untuk dev lokal lewat --dart-define=API_BASE_URL=...
  (sebelumnya satu-satunya cara adalah mengedit file, itulah yang
  menyebabkan bug ini ter-rilis).
- auth_service.dart: _postToAuth() tidak lagi menelan error. Tambah
  timeout 20 detik dan field lastAuthError berisi alasan sebenarnya
  (server menolak / server tidak terjangkau).
- login_screen.dart: tampilkan lastAuthError kalau ada, sehingga
  "Login dibatalkan" hanya muncul saat user memang membatalkan.

Verifikasi: flutter analyze 0 error, build web sukses, bundle hasil
build memuat URL produksi (localhost:3000 = 0 kemunculan), endpoint
auth produksi merespons 401 normal.
